**До трёх ближайших прибытий автобуса в Home Assistant — из JSON API Яндекс Карт.**

Home Assistant custom integration for bus arrivals from Yandex Maps, with
per-arrival forecast/schedule labels, multiple stops and a native Markdown card.

## Возможности

- Настройка по полной ссылке остановки и номерам автобусов через UI.
- Несколько остановок, маршрутов и направлений. Один опрос на остановку.
- До трёх будущих прибытий с отдельной меткой «прогноз» или «по расписанию».
- Честные состояния: нет данных, ошибка запроса и устаревший снимок.
- Автоматическое восстановление, общая пауза при ограничениях источника.
- Настраиваемый режим сна без запросов к источнику, включая интервалы через полночь.
- Карточка из штатных средств HA. Сторонние JavaScript-карточки не нужны.
- Русский и английский интерфейс настройки. Аккаунт Яндекса и API-ключ не нужны.

## Установка через HACS

[![Открыть YaBusTracker в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=moskal43&repository=YaBusTracker&category=integration)

Или вручную: **HACS → меню ⋮ → Пользовательские репозитории**. Укажите
`https://github.com/moskal43/YaBusTracker`, тип **Integration**, затем найдите
YaBusTracker и скачайте его. Перезапустите Home Assistant Core.

После перезапуска: **Настройки → Устройства и службы → Добавить интеграцию →
YaBusTracker**. Вставьте полную HTTPS-ссылку остановки Яндекс Карт, введите номера
автобусов через запятую. При неоднозначности выберите нужные направления.

Минимальная версия HA — **2026.8.3**, на ней выполнены проверки. Интервал:
**60–86400 секунд**, по умолчанию 60. Дополнительные зависимости в Core не нужны.

Установка вручную и переход с неё на HACS: [подробная инструкция](docs/install.md).
Это пользовательский репозиторий HACS; включение в общий каталог не заявляется.

## Карточка

![Пример карточки YaBusTracker](https://raw.githubusercontent.com/moskal43/YaBusTracker/main/docs/images/dashboard-card.png)

Добавьте штатную карточку **Markdown** на существующий дашборд и вставьте
[examples/dashboard.yaml](examples/dashboard.yaml). Замените ID сущности в
двух отмеченных местах на ID вашего датчика YaBusTracker.

Карточка показывает номер, остановку, направление, минуты, источник каждого
прибытия и последнее успешное обновление. Минуты округляются вверх, время
учитывает часовой пояс HA. Обратный отсчёт не создаёт запросов к Яндексу.

Для оформления с тёмной полупрозрачной панелью и тремя компактными блоками
используйте [минималистичный вариант](examples/dashboard-minimal.yaml).
Для переключения автобусов сверху карточки есть
[вариант с выбором маршрута](examples/dashboard-selector.yaml) и
[инструкция настройки](docs/install.md#выбор-автобуса-сверху-карточки).
Он требует **button-card 7+** из HACS; настройте `variables.selector` и
`variables.routes` по инструкции.

## Обновление и настройка

Параметры остановки меняются через **Настроить** в записи интеграции. Новую
остановку добавьте отдельной записью; для второго маршрута той же остановки
измените уже существующую запись.

Там же можно включить режим сна и указать начало и окончание, например
22:00–06:00. Используется локальный часовой пояс Home Assistant. Во время сна
интеграция не опрашивает Яндекс, очищает прогноз и показывает следующую попытку.

Обновления устанавливаются через HACS с последующим перезапуском Core.
Служебный домен `yandex_transit` сохранён для совместимости ранних версий:
название приложения — YaBusTracker, существующие настройки и ID не меняются.

## Границы и надёжность

Используется **недокументированный** API Яндекс Карт. Схема и доступность могут
измениться. Браузер, HTML-парсинг, CAPTCHA и обход ограничений не используются.
При ошибке старый прогноз скрывается; расписание не выдумывается из интервалов.

Функциональные проверки выполнены на HA Core 2026.8.3. Реальная установка,
маршруты одной остановки, перезапуск и обновление карточки проверены. Полная
живая приёмка второй остановки, мобильный UI и длительное наблюдение остаются
задачами дальнейшей проверки. Суточная стабильность и SLA не заявляются.
Подробнее: [ограничения и проверенное поведение](docs/limitations.md).
