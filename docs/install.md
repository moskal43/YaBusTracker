# Установка, обновление и удаление YaBusTracker

Требуется Home Assistant Core 2026.8.3 или новее. Проверенная версия — 2026.8.3.
Python и aiohttp предоставляются самим Core; отдельно устанавливать зависимости
в его контейнер не нужно. Protection mode изменять не требуется.

## Через HACS

1. Откройте HACS → меню ⋮ → **Пользовательские репозитории**.
2. Добавьте `https://github.com/moskal43/YaBusTracker`, категория **Integration**.
3. Найдите **YaBusTracker**, откройте его и нажмите **Скачать**.
4. Перезапустите Home Assistant Core.
5. Настройки → Устройства и службы → Добавить интеграцию → **YaBusTracker**.

Прямое добавление репозитория:

[![Открыть YaBusTracker в HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=moskal43&repository=YaBusTracker&category=integration)

## Настройка

Скопируйте полную HTTPS-ссылку остановки из Яндекс Карт. Поддерживаются URL
с `/stops/stop__…/` и `/stops/group__…/`. Сокращённые ссылки не раскрываются
через браузер: вместо них укажите полную ссылку. Введите номера автобусов через
запятую, например `16, 22А`. Это пример формата, а не готовые настройки остановки.

Номера сохраняются строками. Если одинаковый номер соответствует нескольким
линиям/направлениям, выберите нужные в следующей форме. Запрет посадки учитывается.
Интервал — целое число от 60 до 86400 секунд; начальное значение 60.

Одна запись описывает остановку и набор её направлений. Для изменения маршрутов
или интервала используйте **Настроить**. Несколько остановок добавляются отдельными
записями. Повторное добавление остановки не создаёт дубли.

## Карточка

Добавьте штатную Markdown-карточку и вставьте YAML из
[examples/dashboard.yaml](../examples/dashboard.yaml). Замените ID сущности в
двух отмеченных местах. Для другого направления добавьте ещё одну карточку.

| `status` | Что показывает карточка |
|---|---|
| `ok` | До трёх будущих прибытий с источником каждого времени |
| `no_data` | Нет данных после успешного ответа |
| `error` | Не удалось обновить |
| `stale` | Данные устарели |

При ошибке/просрочке timestamp становится `unknown`, список очищается,
`source_available=false`. Сам локальный датчик остаётся доступным, чтобы HA
сохранил диагностические атрибуты `last_success`, `last_error`, `next_attempt`.
HA не выводит дополнительные атрибуты для сущностей `unavailable`.

Минуты округляются вверх, отображение использует часовой пояс HA. Вызов `now()`
пересчитывает карточку раз в минуту; локальный таймер удаляет истёкшие события
из датчика. Ни то ни другое не является новым запросом к Яндексу.

## Ручная установка

Скачайте архив из [Releases](https://github.com/moskal43/YaBusTracker/releases).
Скопируйте только `custom_components/yandex_transit` в каталог
`/config/custom_components/` своего HA. Не заменяйте весь `custom_components`.
Выполните штатную проверку конфигурации и перезапустите Core, затем добавьте
интеграцию через UI. Встроенный старый Yandex Transport включать не нужно.

Сборка из исходников: `python3 tools/build_release.py`. Архив появится в `dist/`.

## Переход с ручной установки на HACS

1. Создайте резервную копию HA и сохраните текущий каталог компонента вне
   `custom_components`, например в `/config/YaBusTracker-backup/`.
2. Добавьте репозиторий в HACS и скачайте актуальную версию поверх того же домена.
3. Перезапустите Core и проверьте существующую запись и карточку.

Удалять/создавать заново запись не нужно. Домен `yandex_transit` и устойчивые
идентификаторы направлений сохраняются. Если HA предлагает добавить новую
интеграцию, сначала проверьте существующую запись в «Устройства и службы».

## Обновление и откат

Перед обновлением сохраните резервную копию. Установите релиз через HACS и
перезапустите Core. Для отката выберите предыдущую доступную версию в HACS
либо восстановите сохранённый каталог компонента, затем перезапустите Core.
Не восстанавливайте весь чужой конфигурационный каталог ради одного компонента.

## Удаление

Удалите запись остановки в UI HA — это прекращает её опрос. Последняя выгрузка
освобождает собственную HTTP-сессию, не закрывая соединения других интеграций.
Для полного удаления уберите карточки, удалите все записи YaBusTracker,
удалите интеграцию через HACS и перезапустите Core.
